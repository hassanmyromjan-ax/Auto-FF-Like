ধাপ ১: ফোল্ডার ও ফাইল স্ট্রাকচার ঠিক করা
---------------------------------------------------------
আপনার কম্পিউটারে বা মোবাইলে প্রজেক্ট ফোল্ডারটি ঠিক এভাবে সাজানো থাকতে হবে:

Project-Folder/

 ├── accounts.txt               (FF অ্যাকাউন্টের লিস্ট: uid:pass)
 ├── token_bd.json              (ভিতরে শুধু [] লিখে সেভ করবেন)

 ├── uid_generator_pb2.py

     ├── admin_login.html

ধাপ ২: Firebase সেটআপ (Database & Authentication)
---------------------------------------------------------
১. প্রথমে https://console.firebase.google.com/ এ যান এবং একটি নতুন প্রজেক্ট তৈরি করুন (যেমন: FF-Auto-Like)।
২. বাম পাশের মেনু থেকে "Build" এ ক্লিক করে "Authentication" এ যান।
   - "Get Started" এ ক্লিক করুন।
   - Sign-in method হিসেবে "Email/Password" চালু (Enable) করুন।
   - এবার "Users" ট্যাবে গিয়ে "Add User" এ ক্লিক করুন।
   - ইমেইল (admin@gmail.com) এবং পাসওয়ার্ড (roman@pass) দিয়ে এডমিন একাউন্ট তৈরি করুন।
   - একাউন্ট তৈরি হলে ডানপাশে একটি "User UID" দেখতে পাবেন, সেটি কপি করে রাখুন (এটি app.py এবং html ফাইলে বসাতে হবে)।

৩. এবার আবার বামের মেনু থেকে "Realtime Database" এ যান।
   - "Create Database" এ ক্লিক করুন।
   - লোকেশন (Singapore/Asia) সিলেক্ট করে Next দিন।
   - "Start in test mode" সিলেক্ট করে Enable করুন।
   - ডাটাবেস তৈরি হলে উপরের "Rules" ট্যাবে যান এবং নিচের কোডটি পেস্ট করে Publish করুন:
     {
       "rules": {
         ".read": "auth != null && auth.uid == 'আপনার_কপি_করা_UID'",
         ".write": "auth != null && auth.uid == 'আপনার_কপি_করা_UID'"
       }
     }

৪. (ঐচ্ছিক) Project Settings (গিয়ার আইকন) থেকে Web App অ্যাড করে Firebase Config (apiKey, databaseURL ইত্যাদি) কপি করে app.py এবং HTML ফাইলে আপডেট করে নিবেন।

ধাপ ৩: GitHub এ প্রজেক্ট আপলোড
---------------------------------------------------------
১. github.com এ গিয়ে নতুন একটি Repository তৈরি করুন (Private রাখা ভালো)।
২. আপনার সাজানো ফোল্ডারের সবগুলো ফাইল এই রিপোজিটরিতে আপলোড করে Commit করুন।


---------------------------------------------------------
ধাপ ৪: Render.com এ হোস্টিং (Web Service Setup)
---------------------------------------------------------
১. render.com এ লগইন করে Dashboard এ যান।
২. "New" বাটনে ক্লিক করে "Web Service" সিলেক্ট করুন।
৩. "Build and deploy from a Git repository" সিলেক্ট করে আপনার GitHub এর রিপোজিটরিটি কানেক্ট করুন।
৪. সেটিংগুলো নিচের মতো দিন:
   - Name: আপনার সাইটের নাম (যেমন: ff-like-pro-roman)
   - Region: Singapore (বা আপনার পছন্দমতো)
   - Branch: main
   - Runtime: Python 3
   - Build Command: pip install -r requirements.txt
   - Start Command: gunicorn app:app (অথবা python app.py)
   - Instance Type: Free

৫. Environment Variables যুক্ত করা (খুবই গুরুত্বপূর্ণ):
   পেজটি একটু নিচে স্ক্রোল করে "Advanced" এ ক্লিক করুন এবং "Add Environment Variable" এ নিচের ২টি মান বসান:
   - Key: PYTHON_VERSION | Value: 3.11.0
   - Key: PROTOCOL_BUFFERS_PYTHON_IMPLEMENTATION | Value: python

৬. এবার নিচে "Create Web Service" বাটনে ক্লিক করুন। ২-৩ মিনিটের মধ্যে আপনার সাইট লাইভ হয়ে যাবে!


---------------------------------------------------------
ধাপ ৫: সাইট ২৪ ঘণ্টা লাইভ রাখা (Cron Job)
---------------------------------------------------------
Render এর ফ্রি সার্ভার ১৫ মিনিট কেউ ভিজিট না করলে স্লিপ মোডে চলে যায়। অটো-লাইক যেন বন্ধ না হয়, তার জন্য:
১. https://cron-job.org/ এ একটি ফ্রি একাউন্ট খুলুন।
২. "Create Cronjob" এ ক্লিক করুন।
৩. Title: Keep Alive Render
৪. URL: https://আপনার-সাইটের-নাম.onrender.com/ping (আপনার আসল লিংক দিবেন)
৫. Execution schedule: প্রতি 5 মিনিট (Every 5 minutes) সিলেক্ট করুন।
৬. "Create" এ ক্লিক করে সেভ করে দিন।

ব্যাস! আপনার সার্ভার এখন আর কখনো ঘুমাবে না এবং ভোর ৫টায় ঠিকঠাক অটো-লাইক ডেলিভারি করে দিবে।
